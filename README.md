# AI-TEACHER-S-BURNOUT-TASK-AUTOMATER
A Flask web app that helps teachers upload exit tickets, extract responses with OCR, grade by keywords, generate feedback, and view class analytics to reduce repetitive workload.

Teachers spend a significant amount of time on non-teaching activities such as grading assignments, analysing student responses, and identifying learning gaps. These repetitive manual tasks increase workload and contribute to teacher burnout, reducing overall classroom productivity and teaching efficiency. To address this issue, the proposed project, Teacher Burnout Task Automator, introduces an intelligent classroom support system that integrates Optical Character Recognition (OCR) and Artificial Intelligence (AI) technologies for automated student response evaluation.

The system is designed to process handwritten exit tickets submitted by students at the end of a class session. Uploaded images are first enhanced using image preprocessing techniques such as grayscale conversion and noise removal through OpenCV. The processed images are then analysed using Tesseract OCR to extract handwritten text and convert it into digital format. The extracted text is further evaluated using AI-based analysis techniques to identify keywords, determine student understanding, and detect learning gaps.

The analysed results are displayed through an interactive dashboard that provides real-time classroom analytics, performance visualization, and automated feedback generation. This enables teachers to quickly assess student performance and focus more on mentoring and personalized teaching rather than repetitive administrative tasks. The proposed system improves evaluation speed, reduces human error, enhances classroom productivity, and contributes to reducing teacher burnout. Overall, the project demonstrates the effective application of AI and OCR technologies in creating smarter and more efficient educational environments.
